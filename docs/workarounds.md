# Костыли

Журнал вынужденных обходных решений, сделанных ради совместимости с версиями из `main`.
Файл живёт только в ветке `claude-development` и не переносится в `testers-prerelease` и `main`.

Как вести:

- Новый костыль → новая запись сверху, следующий номер `W-NNN`. В коде рядом с костылём — комментарий `// workaround: W-NNN`.
- Костыль убран (например, старый формат больше не поддерживается) → запись удаляется вместе с кодом.
- Пишется по-русски, коротко, без реальных данных пользователя.

Шаблон записи:

```md
## W-NNN. Короткое название

- Дата: ГГГГ-ММ-ДД
- Где: модуль или файлы
- Что сделано: суть обходного решения
- Почему пришлось: какая совместимость с `main` мешала сделать прямо
- Как работает сейчас: что происходит и на что обратить внимание
- Когда можно убрать: условие (например, «после выхода v2.0.0»)
```
