# Цветовые палитры

<!-- Спецификация: в tokens.css ещё не перенесено. После переноса источник истины — tokens.css, этот файл — сводка для людей. -->

Два независимых переключателя у пользователя:

- **Тема:** «Светлая» / «Тёмная».
- **Палитра:** «Стандарт» — по брендбуку РСО; «Не по ГОСТ'у» — шуточное название, цвета из прошлой версии DocAssist.

Вместе это четыре набора цветов. Переключатели меняют только цвета: шрифты, формы (плоские заливки, овалы, без теней), сетка и размеры одинаковые во всех наборах. Шрифты, скругления, тени и анимации прошлой версии не переносятся.

## Как устроено

- На `<html>` два атрибута: `data-theme="light|dark"` и `data-palette="standard|ngost"`.
- В `tokens.css` четыре блока с одними и теми же токенами `--color-*`. Компоненты берут цвета только из них, поэтому переключение работает везде без правок компонентов. Новая роль добавляется сразу во все четыре набора.
- Выбор пользователя — личная настройка, хранится через модуль data.

| Токен                  | Для чего                                           | Стандарт · светлая | Стандарт · тёмная | Не по ГОСТ'у · светлая | Не по ГОСТ'у · тёмная |
| ---------------------- | -------------------------------------------------- | ------------------ | ----------------- | ---------------------- | --------------------- |
| `--color-bg`           | фон страницы                                       | `#FFFFFF`          | `#000000`         | `#F5F7FA`              | `#060A12`             |

| `--color-text`         | текст                                              | `#000000`          | `#FFFFFF`         | `#0B1424`              | `#E8EEF7`             |
| `--color-text-muted`   | второстепенный текст                               | `#595959`\*        | `#A6A6A6`\*       | `#4A5466`              | `#A3B0C4`             |
| `--color-border`       | рамки, разделители                                 | `#C8C8C8`\*        | `#3D3D3D`\*       | `#E1E6ED`              | `#1B2639`             |
| `--color-primary`      | заливки: кнопки, выбранное                         | `#0804FF`          | `#0804FF`         | `#0054A6`              | `#6BA7F2`             |

| `--color-danger-text`  | мелкий текст ошибок                                | `#D71212`\*        | `#FF5C5C`\*       | `#C42B2B`              | `#FF7B7B`             |

\* Производный цвет: в брендбуке его нет, подобран под нужды интерфейса (как уже сделано в `tokens.css`).

**Контраст (WCAG) проверен:** во всех наборах текст на фоне и на плитках не ниже 4.5 : 1. Самое низкое значение — 4.5 : 1, мелкий текст ошибок на сером в «Стандарт · светлая».

- **«Стандарт · тёмная»:** синий `#0804FF` на чёрном — 2.5 : 1. Поэтому синий там только заливка с белым на ней. Синий текст, ссылки, иконки и тонкие линии — через `--color-primary-text`.
- **«Не по ГОСТ'у · тёмная»:** на голубой заливке текст тёмный (`#06121F`). Правило брендбука «на синем только белый» действует только в «Стандарте».
- **Контрастный блок в «Не по ГОСТ'у»** — синие панели, как шапка и панели в прошлой версии.
- **При переносе в токены:** ссылки в `global.css` сейчас красятся `--color-primary`, их нужно перевести на `--color-primary-text`.

## Открытые вопросы (решить при переносе в код)

- Иконка вкладки: светлая или тёмная по теме браузера (вкладка — часть браузера) или по выбору в приложении.
- Цвета направлений (`directions.ts`): остаются ли одинаковыми в «Не по ГОСТ'у» и как выглядят в тёмной теме (светлые оттенки направлений рассчитаны на белый фон).
- Статусы (предупреждение, успех, справка): в брендбуке их нет, в «Не по ГОСТ'у» есть (ниже). Понадобятся для проверки таблицы, тогда же подобрать их для «Стандарта».
- Что включено по умолчанию: тема по системе и палитра «Стандарт»?
