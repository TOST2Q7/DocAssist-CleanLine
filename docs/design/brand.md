# Дизайн: опорные элементы

<!-- Источник истины для кода — src/shared/design/tokens.css. Этот файл — сводка для людей. -->

Основа — брендбук РСО 2025 («Описание брендбука РСО»), шаблоны презентаций и примеры носителей из присланного архива. Сам архив в репозиторий не кладём: в нём коммерческие шрифты и фирменные исходники РСО, а репозиторий публичный.

## Цвета

Основная палитра (RGB из брендбука):

| Цвет   | RGB         | HEX       |
| ------ | ----------- | --------- |
| Синий  | 8 4 255     | `#0804FF` |
| Белый  | 255 255 255 | `#FFFFFF` |
| Серый  | 238 238 238 | `#EEEEEE` |
| Чёрный | 0 0 0       | `#000000` |

- RGB — для экранов, CMYK — для печати. В PDF-логотипах цвета в CMYK, поэтому на экране синий там выглядит приглушённым. Для приложения берём только RGB.
- **Цвета направлений:** у каждого направления свой цвет в трёх оттенках. Использовать другие цвета, кроме закреплённого и основной палитры, запрещено. Сами значения в архиве не пришли.
- Жёлтый и красный со значка «молоток и ключ» — это цвет направления, а не основная палитра.
- **Красный для ошибок** (`#E10812`) — единственное отступление: функциональный цвет интерфейса, не фирменный. Нужно согласовать.

Контраст (WCAG, норма для текста ≥ 4.5):

- белый на синем — 8.5 ✓; **чёрный на синем — 2.5 ✗, нельзя**;
- синий на белом — 8.5 ✓, на сером — 7.3 ✓;
- чёрный на сером — 18 ✓.

## Шрифты

| Роль в брендбуке                        | Шрифт РСО       | В приложении (бесплатная замена) |
| --------------------------------------- | --------------- | -------------------------------- |
| Только основные титулы                  | Actay Wide Bold | Unbounded 600                    |
| Заголовки и текст (regular/medium/bold) | Stolzl          | Montserrat                       |
| Только цифры                            | Stolzl Light    | Montserrat Light                 |
| Объёмный текст                          | Onest Regular   | Onest — тот же, бесплатный       |

- Дескриптор логотипа («РОССИЙСКИЕ СТУДЕНЧЕСКИЕ ОТРЯДЫ») набран Stolzl Bold, «ПУТЁВКА» — Actay Wide Bd. Это проверено сравнением с файлами шрифтов.
- **Stolzl** (The Northern Block) и **Actay Wide** (Arodora) — коммерческие шрифты, «все права защищены». Встраивать их в сайт и класть в публичный репозиторий без веб-лицензии нельзя. Если у РСО есть веб-лицензии, заменить шрифты можно в одном месте (`src/shared/design/fonts.css`).
- Замены подобраны сравнением: Montserrat Bold по ширине и форме букв ближе всего к Stolzl Bold, Unbounded — к Actay Wide (он чуть шире).

## Логотип РСО

- Составной знак: **эмблема** (овал с надписью «труд крут») + **дескриптор** (текст).
- Эмблема без дескриптора — только как аватар в соцсетях.
- Знак используется только в контексте РСО.
- Нельзя: искажать пропорции, добавлять тени, обводки и блики, ставить на плашки, менять цвета и шрифты. Охранное поле соблюдать.

## Логотипы направлений и округов

- **Логотип направления** = иконка в овале + дескриптор.
- **Знак** = иконка в овале.
- **Иконка** = символ без овала и без дескриптора.
- Логотипы округов (ДФО, СЗФО…): дуга-полумесяц от овала + аббревиатура шрифтом Actay Wide + дескриптор Stolzl. Обычно белые на синем.

## Паттерн и графика

- **Паттерн:** сетка из квадратов и прямоугольников (чёрный / синий / белый / серый), внутри — иконки направлений или фигуры из овалов: ряды наклонных овалов, четыре лепестка, стопка овалов, полуовал, четверть круга, `#`, стрелка, надпись #РСО, слоган в плитке («БЕРЁШЬ И ДЕЛАЕШЬ»).
- **Овал** — главная фигура: наклон ≈ 42°, соотношение осей ≈ 1.8 : 1.
- **Тонкие синие линии** по контуру больших овалов — декоративный фон (шаблон презентации).
- **Фото** — в овальной маске или прямоугольником.
- **Заголовки** капсом, плотный интерлиньяж; фон слайдов — белый.
